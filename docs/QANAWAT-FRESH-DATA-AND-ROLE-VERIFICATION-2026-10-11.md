# Qanawat workflow, fresh data and access verification — 11 October 2026

## Changes and preserved records

The owner-authorized operational refresh replaces obsolete evaluation transactions, customer records, stock, queues and operational targets with a small current dataset. It retains all 25 existing accounts, their roles and effective permissions, branch and designated-leader assignments, all eight retained plans, approved commission policies/settings, existing sessions and append-only audit history. A retained plan whose name begins with QA is excluded from the new sample selection; the catalogue itself is preserved as instructed. No customer carrier API or payment gateway is invoked.

The final dataset contains 14 current screenshot sales covering NEW, MNP, P2P, HW, ELIFE, WASEL and VISITOR, across all 12 active sales agents. It includes 48 branch SIMs, nine branch assets, one stock request, 84 product targets, two support tickets, one saved draft and one no-sale feedback record. Removed field tasks remain absent. Customer/order images are synthetic and correspond to saved fields; unknown HW/eLife carrier charges stay unrecorded. Used SIM type and category agree with inventory. Both daily SR batches contain real downloadable Excel workbooks, not placeholder bytes.

The states include seven closed sales, one cancellation attributed to yesterday's original sale date, and six in progress. SR results include matched, mismatch and pending independently of external activation. Calling queues include completed, waiting and documented next-day deferral examples. Backend review uses independent authorized staff. Optional receipts record payment evidence without adding a payment approval gate. Saved leader notifications remain read-only and are not reassigned through later staff edits.

Effective read permission now controls general portal/mobile navigation and direct routes. A recognized role name alone does not grant record access. General backend callers also require read access for the Call team page and its background summary polling; dedicated tele/welcome officers retain their separate queue grants. Administrators still cannot capture or create capture drafts. Tests also cover revoked permissions, cross-role direct requests and account/branch scope. Fresh call history uses a caller authorized for the sale's retained branch, falling back to independent backend staff where there is no eligible scoped caller.

Background refresh formerly replaced the mobile branch dropdown with a four-pixel loading indicator, moving content by 44 pixels. Catalog refresh now keeps mounted content and its height while data loads. Account changes still discard the previous account's catalogue; a revoked branch selection is cleared. Slow automatic polls no longer queue a full-screen loading cycle. An explicit branch change still immediately hides the previous scope's rows, then loads the new scope.

The animated printer header now lays out its logo, replay control and status without splitting the label into tiny fragments. It keeps the same geometry when printing finishes. The mobile weekly chart now uses the current net-sales series, agreeing with the summary and retroactive cancellations; legacy activity remains a compatibility fallback only when the new series is absent.
