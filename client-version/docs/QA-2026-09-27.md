## Reproduction

Run `pytest -q` in the client backend. Run the browser suite with `RELAY_WEB_URL` and private `DEMO_PASSWORD` environment variables. Keep `organization.spec.ts` write tests restricted to an isolated QA database via `RELAY_ALLOW_SETUP_TEST`; the backend WEB_ORIGIN must match the local web origin. `transaction-icons.spec.ts` imports the local Vite module and must run against the development server.

In the mobile directory, run `flutter analyze`, the widget tests, and `flutter drive --keep-app-running --driver=test_driver/integration_test.dart --target=integration_test/transaction_journey_test.dart -d DEVICE --dart-define=API_URL=HOST/api --dart-define=TEST_PASSWORD=PRIVATE_VALUE`. Run visual_audit_test.dart and capture_test.dart separately using the same driver. Approve the Android installation prompt. Install the normal release APK after the device tests.

Evidence is intentionally outside Git under `client-version/output/qa/`.
