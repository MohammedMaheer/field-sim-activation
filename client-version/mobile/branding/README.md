# relay-client identity

Original vector Relay R mark with a live-status dot. SVG is the editable master; PNG is a 1024px export. Android includes five legacy densities, adaptive foreground/background layers, round-icon mapping, and Android 13 monochrome support. The foreground stays inside the central 66dp safe region of a 108dp canvas.

Regenerate from the workspace root: `python scripts/create-relay-icons.py`, then `node scripts/render-relay-icons.cjs`.
